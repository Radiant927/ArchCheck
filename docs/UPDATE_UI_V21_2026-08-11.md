## 二、结果页 V2.1 重构

**目标**：从"按旧专业（Civil/EEE）分类"改为"按角色化 Agent 组织"，信息层级清晰。

1. **按 Agent 分区块**：页面自上而下 ① BIM Reader（QA，IFC 时）→ ② Compliance Judge（判定）→ ④ Reasoner（AI 报告，移到底部）
2. **双栏布局**：左 = 判定明细列表（带专业标签 消防/电气/全楼/结构/冲突 + 严重度 + code_ref）；右 = 平面图
3. **3D 立体视图**：`generate_building_3d` 等轴投影，所有楼层真实房间轮廓立体堆叠 + 楼层俯视选择器
4. **专业筛选器**：全部 / 消防 / 电气 / 全楼 / 结构 / 冲突
5. **动态公式显示**：判定卡片显示"实测 vs 阈值（公式：max(0.2, min(span,6)/20)）"
6. **标准切换对比**：一键对比另一标准的新增/移除问题
7. **Excel/HTML/PNG 导出**：新增 openpyxl 导出（规则/标题/专业/严重度/楼层/位置/引用）
8. **移除人工复核**（用户决策，单独向老师讲 Reviewer）：
   - 移除"⚠️ 待人工复核"徽章（只显示"✅已复核"→ 后全部移除）
   - 移除信任度 0% 仪表盘（付费标准未收录 → 诚实显示，但显得像坏了）
   - 移除 ⑤ Independent Reviewer 区块、说明
   - Reviewer 概念保留在架构页与代码中

## 三、上传页改动

1. **去掉"快速演示"**：删除演示按钮 + Start 的 demo 兜底，**审查必须真实 IFC**
2. **上传后展示生成平面图**：3D 立体视图 + 每层俯视图（楼层选择器）+ 建筑剖面
3. **参数编辑器 🟢/🟠 来源标注**：
   - 🟢 **来自模型**：房间面积、出口数、门宽、疏散距离、楼层数（真从 IFC 解析）
   - 🟠 **默认·待填写**：消防水池、变压器、应急电源、首层疏散总宽、照明/水源/负荷/插座（非 IFC，编辑器补充）
4. **移除 2D 平面图上传入口**：只保留 IFC 上传（审查数据驱动）

## 四、数据诚实化

1. **房间类型**：`_classify_room_type` 无功能线索时返回 **Unknown**（不猜 Office）；只有明确 office/办公 才标 Office；Unknown 配中性色 + 本地化标签
2. **卡片 CSS class**：内联样式抽成 `.card-title/.card-desc/.card-meta/.tag-disc-*/.tag-sev-*`，改一处 class 统一全部卡片
3. **移除假数据回退**：参数编辑器不再回退 DEMO 假数据，未上传时显示"请先上传 IFC"

## 六、Bug 修复

| Bug | 根因 | 修复 |
|---|---|---|
| 卡片后出现裸 `</div>` | `st.markdown('<div>')` 与 `st.markdown('</div>')` **跨块渲染**，独立 `</div>` 变纯文本 | 改 `st.container(border=True)` |
| 参数编辑器崩溃 | 房间 `exit_count`/`door_width_m` 为 None（无门房间），`int(None)` 报错 | None→默认值 |
| 走廊出口数超限 | 真实走廊门很多（21 > 编辑器 `max_value=4`） | 上限提到 50 |
| 本机 ifcgeom 无法处理拉伸几何 | `IfcExtrudedAreaSolid` create_shape 失败 | 生成器改用手动 **IfcFacetedBrep 面片几何** |
| 生成 IFC 解析 0 房间 | 空间需经 **IfcRelAggregates** 关联楼层（不是 IfcRelContainedInSpatialStructure） | 生成器改 IfcRelAggregates |
| 无房间模型门宽/出口为空 | 门无几何 → 无质心 → 无法关联房间 | 门加面片 box 几何 |
