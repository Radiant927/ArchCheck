## 第 1 页 · 之前的情况：关键词搜索的三个硬伤

**【PPT 内容】**

| 硬伤 | 例子 |
|---|---|
| 同义词搜不到 | 搜"逃生"找不到写"疏散"的条文 |
| 中英不互通 | 搜 "exit" 找不到中文"出口" |
| 自然语言问不了 | 只能输关键词，不能问一句话 |

**结果**：用户其实知道要查什么，但搜不出来——知识库"有货却拿不到"。

**【讲稿】**
这是起点。知识库里其实有规范条文，但关键词搜索三条路都堵着：同义词、中英、自然语言。用户不是不知道要查什么，是搜不出来。这周把它打通了。

## 第 2 页 · 这周做了什么①：语义搜索上线（核心）

**【PPT 内容】**

**做法**：把每段规范文本变成一个"语义向量"（1024 维），提问时找"意思最近"的条文——**不管用词一不一样，意思相近就搜得到**。

**技术选型**
| 项 | 选择 | 为什么 |
|---|---|---|
| 模型 | BAAI/bge-m3 | 开源免费·中英双语向量对齐 |
| 推理 | ONNX Runtime CPU | 普通电脑可跑，无需 GPU |
| 语料 | 1590 条 chunk / 6 份免费规范 | 中国 1 份 + 新加坡 5 份 |

**能解决之前什么问题（真实演示）**

| 能力 | 提问 | 命中 |
|---|---|---|
| 同义词 | "逃生楼梯的宽度要求" | GB 疏散楼梯条文 + 新加坡 "1.5m in width" 条文 |
| 中英互查 | "how wide should escape stairs be" | 新加坡 Fire Code 条文 |
| 自然语言 | "住宅的疏散楼梯间里能装燃气管道吗" | GB 燃气管道设置条文 |
| 具体场景 | "地下停车场需要几个安全出口" | GB 汽车库 + "安全出口≥2" 条文 |
| 间接/别名 | "走道尽头房间的疏散要求" | GB 走道尽端房间条文 |

**【讲稿】**
这页是核心。语义搜索把规范文本变成向量，提问时找意思最近的条文。模型选 bge-m3，免费、中英对齐，跑在 CPU 上。五个真实演示：搜"逃生楼梯"能命中写"疏散楼梯"的条文；用英文问能搜到新加坡规范；问"住宅楼梯间能装燃气管道吗"这种整句话，直接命中燃气管道条文。关键词搜索做不到的，现在都做到了。

## 第 3 页 · 这周做了什么②：效果怎么样（量化评测）

**【PPT 内容】**

**评测怎么做**（为了数字可信）
- 63 条测试查询：55 条应命中 + 8 条语料外（测防幻觉）
- 判定到"条文级"：必须命中具体那条条文，不是只看文档
- 难度分级 + 跨文档复合查询 + 同语料 BM25 对照组

**准确率（55 条应命中）**
| 指标 | 数值 |
|---|---|
| 条文级 P@1（第一条就对）| **67%** |
| 条文级 P@3（前三条有对）| **84%** |
| Recall@3（该找的找回了）| **84%** |
| F1 | **75%** |
| 文档级 P@1（对照）| 91% |

**诚实说明**
- 文档级 91% → 条文级 67%：**命中文档 ≠ 找到那条条文**，这是真实差距
- 关键词基线(BM25) 71% ≥ 语义 67%：**语义不替代关键词**，在改写/同义/跨语言上才更强 → 两个都保留

**防幻觉守卫**
- 语料外假阳性：8/8 → 守卫后 **4/8**（减半）
- 正确命中误拒率：**0/55**
- 剩下的 4 例是"领域重叠"（直升机坪/抗震等与消防共享词汇），兜底回退关键词+人工确认

**【讲稿】**
效果怎么证明的。评测做严谨了：63 条测试、判到条文级、加了难度和对照组。结果：第一条就命中 67%，前三条内命中 84%，该找的条文找回 84%。两个诚实说明：文档级 91% 是虚的，条文级 67% 才真实；关键词基线 71% 反而略高，所以语义不是替代关键词，是互补。防幻觉守卫把语料外假阳性减半，55 个正确命中一个没误杀。
