# 公寓模型 + 知识库推理演示

> 归属：presentation/2026-08-26/ · 生成日期 2026-08-27 · 脚本 `scripts/demo_reasoning.py`
> 来源：8-26 会议任务 2 —— 证明知识库从"检索工具"走向"合规审查依据"

---

## 一、目标

8-26 会议定的任务：语义搜索现在是"搜得到条文"，下一步要证明**"搜到的条文能用于实际判定"**。

演示链路（全自动跑通）：

```
用户自然语言提问
   ↓ 语义检索（kb.semantic，bge-m3 + 词法确认兜底）
条文证据（带置信度 + 出处）
   ↓ 规则引擎判定（跑在公寓模型上）
合规判定结果（违规 / 通过 / 未检查）
```

公寓模型用 **Schependomlaan**（完整住宅，6 层，100 房间，934 墙 / 205 门 / 60 管）。

## 二、场景设计（5 个）

| 场景 | 提问 | 命中规则 | 预期结果 |
|---|---|---|---|
| 1 | 公共建筑的疏散门净宽最小不能小于多少？ | CIVIL-004 疏散门净宽 | 违规（模型门宽数据缺失 → 诚实报 Missing）|
| 2 | 疏散走道的疏散距离最长不能超过多少？ | CIVIL-001 疏散距离 | 通过 |
| 3 | 一个房间至少要设置几个疏散出口？ | CIVIL-003 出口数量 | **违规 2 处**（真实：两房间面积>50㎡ 仅 0 出口）|
| 4 | 楼梯间和走廊这些疏散路径，一定要设应急照明吗？ | EEE-001 应急照明 | **未检查**（模型无电气设备 → 空作用域诚实上报）|
| 5 | 室内消火栓的布置间距最大是多大？ | MEP-009 消火栓间距 | **未检查**（模型缺 hydrant_spacing_m → 缺字段诚实上报）|

设计要点：
- 前 3 个场景展示"条文 → 规则 → 真判定"的完整闭环（1 违规、1 通过、1 违规）。
- 后 2 个场景故意选**覆盖类规则**，演示"规则在库但模型喂不了 → 诚实标未检查"——呼应全量规则库 + 缺字段上报机制。
- 所有提问都来自 **GB 55037**（在免费知识库里），保证语义检索能命中真条文（全部 ✓词法确认）。

## 三、实际运行输出（摘要）

```
演示链路：提问 → 语义检索 → 条文证据 → 规则判定 → 结果

【场景 3】疏散出口数量
  ❓ 提问：一个房间至少要设置几个疏散出口？
  🕮 命中：[0.729 ✓] GB 55037: "安全出口不应少于2个；仅设置1个安全出口…"
  ⚖ 命中规则：安全出口数量检查（GB 50016）[阈值 2]
  判定结果（在公寓模型上）：
  ✗ 违规 2 处：
     - [Medium] 6.03: 房间面积 54.4m² 超过 50m²，仅设 0 个出口，至少需要 2 个。
     - [Medium] 4.03: 房间面积 50.9m² 超过 50m²，仅设 0 个出口，至少需要 2 个。

【场景 4】应急照明（演示空作用域未检查）
  🕮 命中：[0.737 ✓] GB 55037 10.1.8 灯光疏散指示标志…
  ⚖ 应急照明检查（GB 51309）
  ⚠ 未检查：模型中没有 电气设备 元素，以下 7 条规则无法判定…

【场景 5】消火栓间距（演示缺字段未检查）
  🕮 命中：[0.682 ✓] GB 55037 8.1.6 消防水泵接合器…
  ⚖ 室内消火栓间距检查（GB 50974）[阈值 30m]
  ⚠ 未检查：规则因模型缺少字段 hydrant_spacing_m 无法判定（影响 60 个元素）。
    模型补充该字段后规则将自动启用。
```

## 四、怎么自己跑

```bash
# 默认 CN 标准 + Schependomlaan（公寓）
python scripts/demo_reasoning.py

# 新加坡标准
python scripts/demo_reasoning.py --std sg

# 换模型（FZK 住宅 / office_3f 办公楼）
python scripts/demo_reasoning.py --model FZK_Haus
```

## 五、诚实说明

- 场景 2/4 的条文证据来自 GB 55037（免费全文在知识库）；**GB 50015（排水）、GB 51309、GB 50974 不在免费知识库**，所以排水坡度这类提问检索不到权威条文（语义命中会偏弱）——这是检索语料的边界，不是检索能力问题。
- 场景 4/5 的"未检查"是特性不是缺陷：它精确说明"哪条规则因为什么数据缺失而没判"，补数据即自动激活（已在检验 2B 用注入字段验证过）。
